# TestMind V1 文档索引

V1 目录保存 Agent 改造前的项目上下文、需求、状态、变更和验收历史。

这些文件用于：

- 了解 V1 已有能力和历史设计背景。
- 确定 V2 改造必须保护的回归链路。
- 追溯 V1.6、V1.7、V1.8 的开发记录。

V1 文档中的“第一阶段”“第二阶段”限制只适用于对应历史阶段，不直接约束 V2。V2 开发应以 `../PROJECT_RECORD.md` 和 `../V2/01_AGENT_DEVELOPMENT_PLAN.md` 为准。

## 文件说明

| 文件 | 作用 |
|---|---|
| `00_PROJECT_CONTEXT.md` | V1 项目背景和原始改造目标 |
| `01_REQUIREMENTS.md` | V1 需求规格与功能范围 |
| `06_CURRENT_STATUS.md` | V1.8 完成后的状态快照 |
| `07_CHANGELOG.md` | V1 版本变更历史 |
| `08_AI_CODING_RULES.md` | V1 历史阶段的 AI 开发规则 |
| `09_ACCEPTANCE_CHECKLIST.md` | V1 功能和回归验收清单 |
