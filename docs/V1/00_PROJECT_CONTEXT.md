## 项目名称

**基于大语言模型的测试管理平台**

## 项目定位

本平台是一个面向软件测试领域的 AI 辅助测试管理平台，探索将大语言模型（LLM）能力引入测试用例管理和自动化测试执行的全链路闭环。

核心价值：通过 LLM 自动生成 pytest 测试代码、智能分析失败原因、汇总生成测试报告，降低接口自动化测试的编写门槛和维护成本。

## 项目性质

计算机相关专业毕业设计项目。基于已有 Demo 进行毕业设计化改造，不从零重写。

## 已有 Demo 能力（V1.5）

当前 Demo 已具备以下功能：

1. **测试用例管理** — API 用例的 CRUD（名称、方法、URL、请求头、请求体、期望结果）
2. **LLM 生成 pytest 测试代码** — 调用 DeepSeek，基于用例信息生成可执行 pytest 代码
3. **规则生成测试代码** — 纯 Python 确定性生成测试代码，无需 LLM 调用
4. **pytest 执行** — subprocess 异步执行测试，采集 stdout/stderr 日志
5. **响应采集** — 从测试输出中提取接口响应状态码和响应体
6. **AI 失败分析** — 对失败执行记录进行 LLM 根因分析，输出结构化分析结果
7. **场景管理** — 场景 CRUD + 有序步骤管理 + 场景一键执行
8. **项目级测试报告** — 一键自动执行全部场景 + LLM 汇总生成结构化报告
9. **参数文件管理** — 在线编辑 parameter.py，支持 `<<变量名>>` 引用

### 核心闭环

```
测试用例管理 → LLM/规则生成 pytest 代码 → pytest 执行 → AI 失败分析 → 测试报告生成
```

## 毕业设计改造目标

在现有 Demo 基础上进行毕业设计化改造，逐步新增以下能力：

1. **项目管理** — 支持多项目，用例、场景、报告归属到具体项目
2. **模块目录树** — 项目下支持多级模块目录，用例按模块分类组织
3. **需求文本管理** — 支持上传/编辑需求文档，作为用例生成的上下文
4. **功能测试用例管理** — 在接口用例之外，新增功能测试用例类型
5. **功能测试用例生成** — 基于需求文本，LLM 生成功能测试用例
6. **用户登录** — 后续实现用户认证与权限管理

### 改造原则
- 基于现有 Demo 改造，不从零重写
- 不破坏已有 AI 生成代码、规则生成代码、pytest 执行、AI 分析、场景执行和报告生成链路
- 增量修改，向前兼容
