# V3 测试能力验收清单

> 新版本门禁尚未执行；旧证据只作复用参考。
> 2026-09-04 调整：基础测试设计与用例生成已进入 V2（其验收在 [V2 清单](../V2/03_ACCEPTANCE_CHECKLIST.md) 的 Artifact / Conversational Editing / UI 域），V3 只验收更高级测试能力。

## 通用
- [ ] V2（对话式 Test Artifact 闭环）已验收，V3 领域 Skill/Tool 不改变正常聊天行为。
- [ ] 身份/项目/环境与每次工具调用关联，权限动态校验。
- [ ] 所有业务写入有明确审批、幂等、审计和失败处理。
- [ ] 不使用未授权真实数据、生产调用或外部提交。
- [ ] 每个 V3 能力复用 V2 Conversation + Agent Loop + Tools + Artifact，不新增独立固定 Workflow Runtime。

## V3.1 API Testing
- [ ] 依据接口文档/OpenAPI 生成与维护 API 测试资产；请求/断言可解释、可局部修正（复用 V2 Artifact 机制）。
- [ ] 详细任务与真实执行范围在 V2-P10 后定义；本节占位，不虚构已通过项。

## V3.2 Failure RCA
- [ ] 使用执行快照而不是当前配置替代旧证据。
- [ ] 事实/假设/缺失信息区分，证据不足返回 inconclusive。
- [ ] 工具诊断不执行任意网络请求；重跑单独审批。
- [ ] 结构化结论（rca_report 之类 Artifact）可追问，固定样本质量评测通过。

## V3.3 Test Data
- [ ] 测试环境白名单、限量、权限和数据生命周期。
- [ ] 不接受模型任意 SQL，不写生产。
- [ ] 审批/幂等/恢复/清理均有验证。

## V3.4 Defect
- [ ] 草稿与事实证据绑定，缺失信息追问，不编造复现步骤。
- [ ] 用户可编辑/复制，版本留痕。
- [ ] 未授权时不连接或提交外部缺陷平台。

## V3.5 Execution / CI（占位）
- [ ] V2-P10 后定义；连接 V1 执行/报告与 CI 的详细验收届时补充。
