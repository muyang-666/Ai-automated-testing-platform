# V3 测试能力验收清单

> 新版本门禁尚未执行；旧证据只作复用参考。

## 通用
- [ ] V2 基础能力已验收，测试 Skill 不改变正常聊天行为。
- [ ] 身份/项目/环境与每次工具调用关联，权限动态校验。
- [ ] 所有业务写入有明确审批、幂等、审计和失败处理。
- [ ] 不使用未授权真实数据、生产调用或外部提交。

## V3.1 用例生成
- [ ] 聊天讨论不自动启动；明确生成意图且来源有效才创建业务 Run。
- [ ] 需求和接口两种来源、范围/覆盖确认、产物解释与局部修正。
- [ ] 场景级去重、覆盖条款关联、未知规则标注和有限修正。
- [ ] 保存只信任服务端候选/版本；来源变化拒绝；重复请求不重复落库。
- [ ] 原业务生成错误（配置/空响应/格式）有真实诊断和验收证据。
- [ ] one-shot 对照质量、成本、延迟和用户接受度，非纯 Fake。

## V3.2 根因分析
- [ ] 使用执行快照而不是当前配置替代旧证据。
- [ ] 事实/假设/缺失信息区分，证据不足返回 inconclusive。
- [ ] 工具诊断不执行任意网络请求；重跑单独审批。
- [ ] 结构化结论可追问，固定样本质量评测通过。

## V3.3 数据准备
- [ ] 测试环境白名单、限量、权限和数据生命周期。
- [ ] 不接受模型任意 SQL，不写生产。
- [ ] 审批/幂等/恢复/清理均有验证。

## V3.4 缺陷描述
- [ ] 草稿与事实证据绑定，缺失信息追问，不编造复现步骤。
- [ ] 用户可编辑/复制，版本留痕。
- [ ] 未授权时不连接或提交外部缺陷平台。
