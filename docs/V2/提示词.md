TestMind V2-P09.3A 开发提示词
开始 TestMind V2-P09.3A。
本轮只实现：
P09.3A — Conversation × Functional Artifact Context
目标：
不新增任何 AI 界面，继续使用现有 Conversation AI，让现有 Agent 能安全地知道当前「功能用例管理」中的 Project、Functional Artifact、选中的 Module / TestCase，并在正常聊天中基于这些上下文工作。

本阶段重点解决：
用户现在在哪个 Project
        ↓
当前 Conversation 操作哪个 Artifact
        ↓
用户当前选中了哪个 Module / Case
        ↓
这些信息如何 snapshot 到当前 Turn
        ↓
Agent 如何理解“这里 / 这个模块 / 这个用例”
本阶段不做 Agent 修改后的 FunctionCasePage 实时刷新。
实时同步、Chat Change Summary、View Changes 等全部留给 P09.3B。
