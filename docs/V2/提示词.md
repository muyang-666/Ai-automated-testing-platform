## 2.1 Artifact mismatch 提交安全

当前：

```text
Page Artifact = B
Conversation Focus = A
```

是否阻止提交部分依赖：

```text
messageNeedsWorkspaceContext()
```

几个关键词。

这不足以保护：

```text
给登录模块补三个边界
删除支付模块
新增第三方登录模块
检查登录测试覆盖
```

这类明显资产操作。

要求重新收敛。

### 原则

FunctionCasePage 当前 Artifact 和 Conversation focus 不一致时：

#### 明确普通聊天 continuation

例如：

```text
继续解释你刚才说的第二点
为什么这么设计？
这个概念是什么意思？
```

允许继续旧 Conversation A。

#### 资产读取/修改指令

例如：

```text
给登录模块补用例
检查覆盖
删掉支付模块
修改这个预期
新增模块
```

不得静默提交到 A。

提示：

```text
当前页面是「Project B」，
但 Agent 仍绑定「Project A」。

请新建对话或切回对应项目。
```

不要为了这个实现复杂 NLP 分类器。

优先使用保守、安全的规则。

如果无法可靠判断资产操作：

> FunctionCasePage mismatch 时默认不携带 Workspace 的资产型操作应被阻止。

保留真正普通 Conversation continuation 的最小白名单/明确路径即可。

不要让用户因为页面上下文错位修改错误项目。

## 2.2 Conversation Snapshot 重新遵守 Project ACL

当前 focused Artifact metadata 不能绕过：

```text
Project ACL
```

要求：

```text

→ snapshot focused_artifact metadata
→ 必须通过当前用户 Project read permission
```

如果权限已经被撤销：

```text

```

不得继续暴露：

```text

artifact title
```

并且后续 Turn 不得获得有效 Artifact Runtime capability。

不要修改：

```text
Project ACL authority
```

本身。

## 2.3 区分 Artifact loading 与 readonly empty

不要继续用：

```text
artifactId == null
```

同时表达：

```text
正在加载
没有 Artifact
无权限创建
```

Functional Workspace 增加明确状态，例如：

```text
artifactState:
loading
ready
empty
error
```

或当前代码体系下等价的最小表示。

### loading

暂时阻止 Workspace-scoped Turn：

```text
当前项目功能用例正在加载
```

### ready

正常携带 Workspace Context。

### readonly empty

例如 Viewer 打开没有 Functional Artifact 的项目：

普通 AI Conversation 仍然允许使用。

但不得伪造 Artifact context。

如果用户要求修改当前测试资产：

Agent/前端明确提示：

```text
当前项目尚无可用的功能测试资产。
```

不要永久锁死整个 Chat。

## 2.4 Artifact Event 不再塞完整 Diff

当前 Agent write 的：

```text
artifact_diff_created
```

不要继续携带完整：

```text
changes[]
```

改为 compact metadata。

推荐：

```json
{
  "artifact_id": 12,
  "from_revision": 20,
  "to_revision": 21,
  "run_id": 1001,
  "conversation_id": 88,
  "summary": "Added 3 test cases",
  "change_counts": {
    "added": 3,
    "updated": 0,
    "deleted": 0,
    "moved": 0
  }
}
```

可以保留：

```text
artifact_revision_created
```

和：

```text
artifact_diff_created
```

两个事件，也可以合理收敛。

但：

```text
SSE = notification / metadata
```

不是完整 Diff transport。

完整 Diff 仍然：

```text
GET /test-artifacts/{id}/diff
```
